# Наш уютный вечер в Костроме 🍂

Сайт для вечера 2 октября: план, развлечения и закрытое до раскрытия сюрприза дело №24 для совместной игры на телефоне или ноутбуке.

## Что внутри
- план вечера с сохранением галочек;
- рандомайзер из 6 фильмов;
- 30 загадок «фильм по эмодзи»;
- 5 разговорных игр по 10 вопросов;
- детектив с отдельными документами, устройствами, допросами, доской и подсказками;
- экспорт и импорт сохранения дела кнопками «Копия дела» и «Восстановить»;
- адаптация под телефон и ноутбук;
- детективные фотографии находятся в `assets/case/` и сохраняются для работы без сети после первого успешного открытия сайта.

Для игры без сети откройте опубликованный сайт с доступом к интернету и дождитесь загрузки. После этого браузер может открыть сохранённую версию сайта и фотографии без соединения. Если браузер очистит данные сайта, потребуется снова открыть страницу онлайн. Сохранение прогресса находится в памяти этого браузера; отдельный файл можно перенести на другое устройство.

Портреты исходно взяты с Random User Generator, предметные фотографии — с Pexels и Unsplash; копии для офлайн-игры сохранены в проекте в WebP.

## GitHub Pages
1. Repository → Settings → Pages.
2. Source: Deploy from a branch.
3. Branch: main.
4. Folder: / (root).
5. Save.

Если репозиторий private и Pages недоступен на текущем тарифе, переключить Visibility на Public в Settings → General → Danger Zone.
